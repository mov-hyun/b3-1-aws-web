## 반영한 보완

1. 삭제된 IP로 검증 명령을 실수로 다시 실행하지 않도록 실행 파일 대신 [과거 명령 기록](logs/verification-commands.md)으로 보관했습니다. 재배포 시 새 IP·키·검증한 호스트 키를 사용하도록 명시했습니다.
2. [정리 체크리스트](cleanup-checklist.md)의 최종 확인 시각을 KST와 UTC로 함께 표기했습니다.
3. 아키텍처 재생성 도구가 Windows의 맑은 고딕 폰트를 사용하는 조건을 README에 명시했습니다.

## 검증 범위와 남은 제한

이번 검토는 보관된 실제 실행 로그와 문서·코드의 일치 여부를 확인했습니다. 삭제된 EC2를 재생성하거나 반환된 과거 IP에 새 요청을 보내지 않았습니다.

- 외부 접속 스크린샷은 실제 curl 응답의 저장 로그 뷰어이며, 공인 IP를 직접 연 브라우저 화면은 아닙니다. 제출은 방식 B입니다.
- IAM의 지역·MFA·태그 제한은 정책 JSON에서 확인했습니다. 허용되지 않은 각 작업을 실제 호출하는 부정 테스트는 수행하지 않았습니다.
- Billing의 최종 금액·잔여 크레딧은 IAM 조회 권한 제한으로 미확인입니다. 실습 자원 삭제 완료와 구분해 기록했습니다.
- Nginx 검증 로그의 MIME 해시 경고는 남아 있습니다. 설정 검사는 성공했고 당시 내부·외부 응답은 정상입니다.
